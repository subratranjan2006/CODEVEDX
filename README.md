# 📶 Hostel Wi-Fi Usage Prediction System

## 📌 Project Overview

This project was developed as part of my AI/ML Internship at CODEVEDX.
The objective of this project is to predict hostel Wi-Fi data usage based on the number of students and their study hours. A Machine Learning model is trained using a generated dataset and then used to estimate Wi-Fi usage.

## 🚀 Features
- Generate a hostel Wi-Fi dataset
- Analyze the dataset
- Visualize data using graphs
- Train a Machine Learning model
- Predict Wi-Fi data usage
- Save the trained model for future use

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
